# Dataset de estaciones Ecobici

- Fuente: Buenos Aires Data, recurso GeoJSON `e62fb076-dc64-4c42-b8ea-a8dd47395062`.
- URL: https://data.buenosaires.gob.ar/dataset/estaciones-bicicletas-publicas/resource/e62fb076-dc64-4c42-b8ea-a8dd47395062
- Archivo descargado: `ecobici-stations.geojson`.
- Fecha de descarga: 2026-09-05.
- Licencia informada por el portal: CC-BY-2.5-AR.

La capacidad se obtiene de la propiedad `ANCLAJES`. El identificador externo combina `ID` y `NUMERO` porque el
recurso reutiliza algunos valores individuales. El importador también evita los registros compuestos repetidos.
